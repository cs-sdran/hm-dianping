# 异步秒杀完整链路联调报告

日期：2026-10-17。本次 9 项真实链路检查全部通过，实际创建并持久化 14 张订单，订单号全部唯一。两个应用日志中未发现 ERROR、后台下单失败或异常记录。

## 实际运行的链路

通过 `POST /voucher/seckill` 创建新券，真实写入 MySQL，提交后初始化 Redis。随后使用测试用户会话调用 `POST /voucher-order/seckill/{id}`，执行活动检查、Redisson 锁、Lua 预扣、Java 队列提交及后台事务落单。

测试运行两个独立应用 JVM，共享独立 MySQL 测试库和独立 Redis。每次接口返回受理成功后，轮询真实订单表，核对订单号、用户 ID 和优惠券 ID；不把 HTTP 成功直接当作落单成功。

测试会话预置在测试 Redis 中，请求经过项目真实登录拦截器恢复身份。本次不测试验证码发送或登录接口。
